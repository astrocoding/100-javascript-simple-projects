# Mini Project Javascript

Kumpulan mini project sederhana menggunakan JavaScript, HTML, dan CSS. Setiap project berada di folder terpisah dan dapat dijalankan langsung di browser.

## Daftar Project

| No  | Nama Project           | Deskripsi Singkat |
|-----|------------------------|-------------------|
| 001 | RGB Slider             | Slider untuk mengatur warna RGB secara interaktif. |
| 002 | Age Calculator         | Kalkulator umur berdasarkan tanggal lahir. |
| 003 | Stopwatch              | Stopwatch sederhana dengan fitur start, stop, dan reset. |
| 004 | Digital Clock          | Jam digital real-time yang responsif. |
| 005 | Password Generator     | Generator password acak dengan opsi panjang dan karakter. |
| 006 | OTP Generator          | Membuat kode OTP acak untuk verifikasi. |
| 007 | Countdown Timer        | Timer mundur dengan input waktu custom. |
| 008 | Palindrome Checker     | Mengecek apakah sebuah kata/kalimat adalah palindrome. |
| 009 | QR Generator           | Membuat QR code dari teks yang dimasukkan. |
| 010 | Pomodoro               | Timer Pomodoro untuk produktivitas kerja/belajar. |
| 011 | Quotes Generator       | Menampilkan kutipan motivasi secara acak. |
| 012 | Text to Speech         | Mengubah teks menjadi suara dengan Web Speech API. |
| 013 | Voice Recorder         | Merekam suara dan menyimpan hasil rekaman. |
| 014 | Video Player           | Pemutar video custom dengan kontrol lengkap dan pilihan resolusi. |

## Cara Menjalankan

1. Pilih folder project yang ingin dijalankan.
2. Buka file `index.html` di browser.
3. Semua project dapat dijalankan secara lokal tanpa instalasi tambahan.

## Kontribusi

Silakan tambahkan project baru dengan format folder berisi `index.html`, `script.js`, dan `styles.css`.
Tambahkan deskripsi singkat di README ini agar dokumentasi tetap terupdate.
